# MediGuide

MediGuide is a Python-based educational health information assistant.

The project provides a Tkinter graphical user interface (GUI) and a
command-line interface (CLI). It demonstrates Python programming,
input validation, rule-based symptom matching, and basic software
testing.

> **Medical Disclaimer:** MediGuide is an educational project.
> Its symptom-matching results are not a medical diagnosis and should
> not replace advice from a qualified healthcare professional.

---

## Features

- Tkinter-based graphical user interface
- Command-line interface
- Respiratory symptom analysis
- Digestive symptom analysis
- Skin symptom analysis
- Rule-based symptom matching
- General health information
- Input validation
- Automated unit tests

---

## Technologies Used

- Python 3
- Tkinter
- Python standard library
- `unittest`
- Git and GitHub

No external Python packages are required for the current version.
